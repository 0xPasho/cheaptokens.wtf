# ADR-0047 · Retirar el logo de NibbleRouter

- **Estado:** Aceptada
- **Origen:** Usuario
- **Fecha:** 2026-11-12
- **Actualiza:** marca de cabecera y favicon trasladados en ADR-0036.

## Decisión

Retirar los dos SVG del logo de NibbleRouter y su referencia como favicon. La cabecera muestra el nombre `cheaptokens.wtf` como enlace de inicio, conservando el estilo visual y los logos oficiales de modelos y autores. El buscador puede reducirse para mantener la cabecera dentro del ancho disponible.
