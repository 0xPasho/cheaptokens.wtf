# ADR-0043 · Tarjeta clara arriba y autor abajo

- **Estado:** Aceptada
- **Origen:** Usuario
- **Fecha:** 2026-11-12
- **Reemplaza:** distribución de contenido de ADR-0042.

## Decisión

La tarjeta clara ocupa la parte superior y contiene logo, nombre, descripción y etiquetas del modelo. Debajo, fuera de esa tarjeta y sobre la base oscura, aparecen únicamente el autor y el tipo de tarea. El estado deprecado, cuando aplica, forma parte de las etiquetas superiores.

Se conservan las superficies, radios, tamaños de logos, enlace de tarjeta y comportamiento responsive de ADR-0042.
