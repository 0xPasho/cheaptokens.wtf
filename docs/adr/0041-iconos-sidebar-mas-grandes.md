# ADR-0041 · Iconos de sidebar de 24 px

- **Estado:** Aceptada
- **Origen:** Usuario
- **Fecha:** 2026-11-12
- **Actualiza:** tamaño de iconos en ADR-0038.

## Decisión

Los iconos funcionales Kubai de la sidebar pasan de 18 a 24 px para que se reconozcan mejor. El usuario excluye los logos de modelos de este aumento. Los logos de autores también conservan sus 18 px, con margen lateral para alinear las etiquetas con las filas Kubai. Se mantiene el acabado Ink.
