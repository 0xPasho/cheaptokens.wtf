# Model and provider marks

The model marks are local SVG reproductions distributed by [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), downloaded on 2026-11-12. Their MIT license is included in `LOBE-ICONS-LICENSE`. Brand marks belong to their respective owners.

| File | Brand |
| --- | --- |
| claude-color.svg | Claude, terracotta spark |
| gemini-color.svg | Gemini, multicolor gradient |
| deepseek-color.svg | DeepSeek, blue |
| qwen-color.svg | Qwen, blue |
| meta-color.svg | Meta, blue gradient, used for Llama |
| openai.svg | OpenAI, monochrome Blossom; inverted for dark surfaces |
| google-color.svg | Google, multicolor corporate G, used for author attribution |
| anthropic.svg | Anthropic, monochrome corporate mark, used for author attribution |

Brand references: [Anthropic press kit](https://www.anthropic.com/press-kit), [Gemini visual design](https://design.google/library/gemini-ai-visual-design), [OpenAI design guidelines](https://openai.com/brand/).

The imported catalog also uses Lobe Icons assets `moonshot.svg`, `kimi-color.svg`, `minimax-color.svg`, `mistral-color.svg`, `xai.svg`, `xiaomimimo.svg`, `zai.svg` and `muse-color.svg`. `kimi-dark.svg` changes only the monochrome mark to white, retaining the original blue accent. Xiaomi's corporate symbol comes from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/xiaomi.svg), with its published brand color; its license is in `SIMPLE-ICONS-LICENSE`.

The other SVGs were copied from the user-supplied NibbleRouter reference. Corporate marks appear beside author names in the sidebar and card footers; Claude and Gemini model marks appear in the model headings.
